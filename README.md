# Calculator App

## About

SimpleCalculator is a basic Android calculator created using MIT App Inventor.

## Features

- **Addition**
- **Subtraction**
- **Multiplication**
- **Division**
- **Clear and Reset**

## Technologies Used

- **MIT App Inventor**
- **Android APK**

## Project Files

- `SimpleCalculator.aia` – Editable MIT App Inventor project.
- `SimpleCalculator.apk` – Installable Android application.
- `README.md` – Project documentation.

## How to Install

1. Download the `SimpleCalculator.apk` file.
2. Open the APK on your Android phone.
3. Allow installation from the source if prompted.
4. Tap **Install** and open the app.

## How to Use

1. Open the Calculator App.
2. Enter numbers using the calculator buttons.
3. Select an arithmetic operator.
4. Press `=` to see the result.
5. Press `C` to clear the calculation.

## Objective

To develop a simple and user-friendly Android calculator using MIT App Inventor and learn the basics of mobile application development.
